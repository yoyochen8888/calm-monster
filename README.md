# 情緒怪獸冷靜站

陪孩子面對挫折、生氣、難過、不服氣等情緒的小工具。孩子選年齡和「情緒怪獸」，跟著呼吸、戳泡泡、擠檸檬等活動讓情緒慢慢變小，再一起說出發生了什麼、想好下次可以怎麼做。

## 給誰用
- 孩子：3–5 歲、6–8 歲、9–12 歲，內容依年齡調整
- 大人：「大人看這裡」提供各情緒的引導語、避免說的話、冷靜計時器
- 情緒超過孩子能自己處理的程度（4–5 級）時，有「陪伴模式」讓大人接手

## 遊戲系統
- 主角：小狐狸、小熊、小兔子、小貓，可取名字，有自己的經驗等級
- 情緒怪獸：六隻各有顏色與等級，越熟越會變（臉紅、閃光、金色光環）
- 星星：每完成一步立即獲得；獎勵「面對和嘗試」，沒有失敗扣分
- 家園：用星星買樹、花、帳篷、房子等布置；植物每天澆水會長大（不會枯萎）
- 平時獎勵：心情打卡、平時練習、大人給星星（大人按住確認）
- 兌換券：星星可換大人設定的真實活動與特權（如多聽一本故事），大人按住確認兌現
- 情緒紀錄：自動記錄每次情緒事件與處理方式，含週摘要，可複製分享
- 一週練習表：心情打卡、平時練習、紅綠燈、角色扮演、特別時光等每日任務
- 遊戲時間：每天 10 分鐘（熱身→專注→情緒→收尾）、記憶翻牌（比賽／合作，練習輸了怎麼面對）、烏龜兔子石頭、顏色泡泡、12 個親子遊戲玩法卡
- 怪獸圖鑑：每隻怪獸的介紹、身體訊號、相處方法、個人最有效方法、孩子的冷靜秘訣
- 修復任務：破壞或傷人後選擇彌補方式，完成後大人確認，獲得「負起責任」獎勵

## 隱私
本工具不收集、不上傳任何資料。年齡設定與徽章數量只存在使用者自己的瀏覽器裡。

## 提醒
這是日常情緒陪伴的小工具，不能取代專業評估。若孩子情緒爆發頻繁、強度大、持續很久，或有傷害自己或他人的情形，請諮詢兒童心智科醫師、心理師或學校輔導老師。
