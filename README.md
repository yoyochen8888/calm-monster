# 情緒怪獸家園

陪孩子面對挫折、生氣、難過、不服氣等情緒的小工具。孩子選年齡和「情緒怪獸」，跟著呼吸、戳泡泡、擠檸檬等活動讓情緒慢慢變小，再一起說出發生了什麼、想好下次可以怎麼做。

## 給誰用
- 孩子：3–5 歲、6–8 歲、9–12 歲，內容依年齡調整
- 大人：「大人看這裡」提供各情緒的引導語、避免說的話、冷靜計時器
- 情緒超過孩子能自己處理的程度（4–5 級）時，有「陪伴模式」讓大人接手

## 遊戲系統
- 主角：小狐狸、小熊、小兔子、小貓，可取名字，有自己的經驗等級
- 情緒怪獸：六隻各有顏色與等級，越熟越會變（臉紅、閃光、金色光環）
- 星星：每完成一步立即獲得；獎勵「面對和嘗試」，沒有失敗扣分
- 家園：用星星買樹、花、帳篷、房子等布置；植物每天澆水會長大（不會枯萎）
- 療癒小角落：池塘（碰水面有漣漪、撒飼料看魚游過來，魚吃飽會自己去荷葉下休息）、菜園（按住慢慢澆水、聽雨聲，收成分給怪獸吃）。沒有倒數和進度數字，照顧每天第一次 +1 星
- 看魚呼吸：冷靜站的冷靜方法之一，跟著池塘裡的圈圈吸氣、吐氣
- 平時獎勵：心情打卡、平時練習、大人給星星（大人按住確認）
- 兌換券：星星可換大人設定的真實活動與特權（如多聽一本故事），大人按住確認兌現
- 情緒紀錄：自動記錄每次情緒事件與處理方式，含週摘要，可複製分享
- 一週練習表：心情打卡、平時練習、紅綠燈、角色扮演、特別時光等每日任務
- 遊戲時間：每天 10 分鐘（熱身→專注→情緒→收尾）、記憶翻牌（比賽／合作，練習輸了怎麼面對）、烏龜兔子石頭、顏色泡泡、12 個親子遊戲玩法卡
- 怪獸圖鑑：每隻怪獸的介紹、身體訊號、相處方法、個人最有效方法、孩子的冷靜秘訣
- 修復任務：破壞或傷人後選擇彌補方式，完成後大人確認，獲得「負起責任」獎勵

## 程式在哪裡
- `index.html`：畫面（每一頁的內容）
- `css/style.css`：顏色、大小、排版
- `css/clay.css`：黏土小島外觀（v32）。只蓋掉外觀、不動功能；把 `index.html` 裡載入它的那一行拿掉就會回到原本的樣子
- `js/data.js`：資料與設定（怪獸、年齡、引導語、商店物品），也負責存檔
- `js/art.js`：黏土感畫風（家園物件、蔬菜、暫代怪獸）＋換成自己圖片的設定（`ART`）
- `js/icons.js`：黏土圖示（家園三個入口、心裡的天氣）
- `js/core.js`：音效、語音、怪獸圖、換頁
- `js/calm-flow.js`：冷靜流程（陪伴模式、選怪獸、溫度計、冷靜活動、說說看、下次怎麼做）
- `js/home.js`：圖鑑與怪獸介紹、主角、家園、大人給星星、商店
- `js/records.js`：情緒紀錄、一週練習表、兌換券
- `js/games.js`：遊戲時間與安靜觀察
- `js/corners.js`：療癒小角落（池塘、菜園）與看魚呼吸
- `js/parent.js`：大人區、使用時間提醒、測試模式、計時器
- `js/ambient.js`：環境音（預設關閉）與「靜靜看」
- `js/intro.js`：第一次打開的使用說明
- `js/wish.js`：願望罐（延遲滿足）
- `js/review.js`：一起回顧（事後帶孩子回頭看那一次）
- `js/backup.js`：加到主畫面的說明、離線狀態、備份與還原
- `js/main.js`：啟動
- `sw.js`：離線快取。**每次更新程式或圖片，都要改裡面的 `VERSION`**（例如 v21 → v22），新增檔案也要加進 `FILES`，裝置才會抓到新版
- `manifest.webmanifest`、`icons/`：加到主畫面時的名稱和圖示

## 加到主畫面、離線、備份
- 用 Safari（iPad／iPhone）開網頁 → 分享 → 加入主畫面，之後一點就開，沒有網路也能用
- 「大人看這裡」→「加到主畫面、備份紀錄」可以把紀錄備份成檔案或文字，換裝置或清除瀏覽資料後再還原
- iPad／iPhone 的主畫面版本和 Safari 的紀錄是分開的，要用備份、還原搬過去

## 隱私
本工具不收集、不上傳任何資料。年齡設定與徽章數量只存在使用者自己的瀏覽器裡。

## 提醒
這是日常情緒陪伴的小工具，不能取代專業評估。若孩子情緒爆發頻繁、強度大、持續很久，或有傷害自己或他人的情形，請諮詢兒童心智科醫師、心理師或學校輔導老師。

## 圖片來源
角色與情緒設計由作者構思；家園物件、池塘、菜園與 8 隻暫代怪獸是用程式畫的（`js/art.js`），之後可以逐一換成生成圖，方法寫在 `art/PROMPTS.md`。主角與 6 隻怪獸的圖片由作者使用 Google Gemini 依提示詞生成、挑選與修改，並經切圖整理。提示詞與原始圖檔紀錄在 `art/PROMPTS.md`、`art/source/`。
