# 角色規格（以生氣怪獸為標準｜2026-11-28）

新生成或重畫的角色圖都照這份檢查。參考圖：`img/angry0.webp`～`angry4.webp`、`img/angryg1.webp`～`angryg4.webp`。

## 外型
- **身體**：圓圓胖胖的身體，肚子有一塊比身體淺的橢圓；頭身一體（沒有脖子）
- **手腳**：短短圓圓的手和腳，手比身體寬一點點伸出來；不要細長的手腳
- **臉**：
  - 眼睛：大圓眼，深棕色，**左上有白色亮點**；有眉毛（情緒的表情主要靠眉毛和嘴巴）
  - 腮紅：兩頰淡淡的粉色圓
  - 嘴巴：小小的，平靜時是溫和的微笑
- **特徵**：每隻一個代表情緒的造型（生氣＝頭頂小火焰、毛刺），造型做在「身體上」，道具（沙漏、書、蝸牛）盡量少、放身體旁邊
- **情緒大小 1→4**：眉毛越壓越低、嘴巴越張越大、手腳動作變大；越大越激動但**不可怕**
- **成長 1→4**：越來越高、表情越來越穩，**不會變兇**

## 質感與光線
- 3D 黏土玩具感、霧面、柔和的小毛邊或細紋理
- 光從**左上**來，暖色柔光；陰影柔，不要硬邊高光（量化：亮度約 0.55–0.66、對比 ≤ 0.115，用 `tools/tone.py` 檢查）
- 粉彩但飽和度依每隻的代表色，不刻意拉齊

## 圖檔
- 正面、全身、**頂滿畫布高度裁切**（網站用同一條基準線擺放，影子由程式畫）
- 背景去掉；不畫地面影子
- 檔名：`{key}0–4.webp`（平靜＋4 種大小）、`{key}g1–4.webp`（成長）；寬高比不是 1 的話，寫進 `js/data.js` 的 `ASPECT`
- 處理：`python3 tools/tone.py img 輸出資料夾 --dry` 先看數值，再正式處理

## 目前跟標準差比較多的（2026-11-28 盤點）
- 做不到（stuck）：毛線球身體、細手腳、小黑點眼睛
- 壓力（stress）：整隻是書包、旁邊有書
- 孤單（lonely）：燈籠會發光（光線方向跟大家不一樣，是設計）
- 難過（sad）：平靜版是瞇眼，跟大家的大圓眼不同
